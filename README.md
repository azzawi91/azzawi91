## 🔬 Research in code

**How should a wearable sensor choose a route for its data?** In [PhysaRoute](https://github.com/azzawi91/PhysaRoute), I explore an idea borrowed from slime mould. Links that carry traffic grow stronger, while unused links gradually weaken. The repository includes Python experiments for studying the trade-off between reliable delivery and energy use in body area networks.

My other research repositories cover [behavioral drift in IoT](https://github.com/azzawi91/behavioral-drift-iot) and [task-oriented semantic communication for ECG signals](https://github.com/azzawi91/task-oriented-semantic-ecg).
